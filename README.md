
# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash shell script
that calculates simple interest based on user input.

## Input

The program accepts three values:

- Principal amount (p)
- Annual rate of interest (r)
- Time period in years (t)

## Formula

Simple Interest = (p * r * t) / 100

## Example

Principal = 1000
Rate = 5
Time = 2

Simple Interest = (1000 * 5 * 2) / 100
Simple Interest = 100

## How to Run

Clone the repository and execute:

```bash
bash simple-interest.sh
```

Enter the principal, rate, and time when prompted.
