
# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to the Simple Interest Calculator project!

## Contributions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

We appreciate everyone who wants to improve this project.

## How to Contribute

1. Fork this repository on GitHub.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Make the necessary changes.
5. Test your changes.
6. Stage your changes using git add.
7. Commit your changes using git commit.
8. Push your branch to GitHub.
9. Open a pull request.

## Bug Reports

If you find a bug, please create an issue on GitHub.

Include the following information:

- Description of the bug
- Steps to reproduce the issue
- Expected behavior
- Actual behavior

## Bug Fixes

Bug fixes are welcome. Please describe the problem and explain how your changes solve it.

## Documentation Improvements

You can improve README.md, fix spelling mistakes, update examples, and make the documentation easier to understand.

## Enhancements and Ideas

Suggestions for new features and improvements are welcome.

## Code Guidelines

- Write clean and readable code.
- Use meaningful variable names.
- Add comments when necessary.
- Test your code before submitting changes.
- Follow Bash scripting best practices.

## Pull Requests

Before submitting a pull request:

1. Make sure your code works correctly.
2. Provide a clear description of your changes.
3. Explain the purpose of your changes.
4. Wait for review from the project maintainer.

## Code of Conduct

All contributors are expected to follow the CODE_OF_CONDUCT.md guidelines.
